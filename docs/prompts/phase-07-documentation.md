# Phase 7: Documentation

Create a Markdown file named `API_DOCUMENTATION.md` containing:

- Base URL and general description
- Authentication (how to get and use a token)
- For each Endpoint:

  - Method and Route
  - Description
  - Required Auth (Public/User/Admin)
  - Request Body (JSON sample)
  - Query Parameters (for Get/List)
  - Response sample (Success and Error)
  - Status Codes

- Common errors table
- Full example flow (Register → Login → Add to Cart → Order)

Group endpoints by Controller.
